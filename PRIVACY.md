# Privacy Statement

## Realigns Local Studio v1

Realigns Local Studio v1 is designed for private local AI workflows on user-controlled computers.

## Local-First Design

By default:

- User prompts stay on the local machine.
- Uploaded GGUF models stay on the local machine.
- Local document processing stays on the local machine.
- Local AI conversations are processed through the local runtime.
- No external AI API is required by default.

## No Bundled Models

Realigns Local Studio v1 does not include GGUF model files inside the installer. Users or organizations provide their own approved model files.

## Optional Internet Use

Some features may require internet access, including:

- License activation
- Updates
- Optional web research
- Online documentation
- Support access

When optional web-enabled features are used, relevant network requests may occur.

## User Responsibility

Organizations are responsible for:

- Choosing approved models
- Managing confidential documents
- Applying internal AI policies
- Ensuring compliance with local laws and industry requirements
- Controlling access to installed systems
