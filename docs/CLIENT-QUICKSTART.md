# Client Quickstart

## Realigns Local Studio v1

1. Download the installer for your system.
2. Install Realigns Local Studio v1.
3. Open the application.
4. Activate your license or trial access.
5. Open Model Manager.
6. Upload your approved GGUF model.
7. Select the model.
8. Start Runtime.
9. Open Chat Studio or another workspace.
10. Begin using private local AI.
