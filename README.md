# Realigns Local Studio v1

**Private Local AI for Mac and Windows — Licensed by Realigns Inc.**

Realigns Local Studio v1 is a commercial desktop AI application designed for organizations, professionals, and controlled business environments that need private AI workflows on their own computers.

The application supports local GGUF model usage, private document workflows, AI chat, research assistance, coding assistance, presentation support, local model management, and responsible AI controls.

## Key Positioning

Realigns Local Studio v1 is designed for private and controlled AI use.

Unlike cloud-only AI tools, Realigns Local Studio v1 allows users to run supported local GGUF models directly on their own Mac or Windows machine. Prompts, local files, uploaded models, and AI activity remain on the user-controlled system by default.

## Main Features

- Private local AI on user-controlled machines
- GGUF model upload and selection
- Built-in local runtime
- Chat Studio
- Document Studio
- Research Studio
- Coding Studio
- PPT Studio
- Model Manager
- Local API Gateway
- Security Console
- Responsible AI Controls
- Commercial license activation
- No external AI API required by default
- No GGUF model files bundled with the installer

## Important Privacy Note

Realigns Local Studio v1 does not bundle GGUF models. Users must upload their own approved GGUF model after installation.

By default, local AI workflows are processed on the user’s own machine. Optional web-enabled features, if used, may require internet access.
