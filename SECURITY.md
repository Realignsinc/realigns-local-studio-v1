# Security Notes

## Realigns Local Studio v1

Realigns Local Studio v1 is commercial desktop software licensed by Realigns Inc.

## Security Design

The application is designed with:

- Local-first AI processing
- License-controlled access
- No bundled GGUF model files
- Local model management
- Local runtime execution
- Responsible AI controls
- Reduced dependency on third-party AI APIs by default

## Download Safety

Only download Realigns Local Studio v1 from official Realigns channels:

- Realigns official website
- Official GitHub Releases
- Authorized client delivery links

Do not download modified copies from unknown sources.

## Installer Signing Status

Public builds may require additional code signing and notarization for smooth installation:

- Mac: Apple Developer ID signing and notarization
- Windows: Authenticode code signing

Unsigned builds may trigger operating system security warnings.

## Reporting Security Issues

Please report security issues privately:

support@realignsinc.com

Do not publicly disclose sensitive issues before Realigns has reviewed them.
